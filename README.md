# Sistem-Manajemen-Rental-PlayStation-Berbasis-C-
📌 Deskripsi Proyek

Aplikasi Sistem Manajemen Rental PlayStation ini merupakan program berbasis C++ (console) yang dirancang untuk mengelola proses penyewaan konsol PlayStation secara terstruktur dan efisien.
Program ini mengimplementasikan berbagai struktur data seperti Binary Search Tree (BST), Linked List (Single & Double), Hash Table, dan Graph untuk mensimulasikan sistem rental di dunia nyata.

Aplikasi mendukung dua peran utama, yaitu Admin dan Customer (Member & Non-Member), dengan fitur yang berbeda sesuai hak akses masing-masing.

✨ Fitur Utama

🔹 Manajemen Konsol (Tree / BST)

Menyimpan data konsol PS1–PS4
Mencari konsol dengan cepat
Mengelola status tersedia & disewa

🔹 Manajemen Pelanggan (Tree / BST)

Menyimpan data pelanggan non-member
Pencarian pelanggan berdasarkan ID
Monitoring status sewa

🔹 Sistem Member (Linked List)

Registrasi & login member
Navigasi data member (next & prev)
Penyimpanan riwayat sewa member

🔹 Manajemen Sewa (Linked List)

Sewa dan pengembalian konsol oleh member
Perhitungan biaya otomatis
Riwayat sewa tersimpan per user

🔹 Game Management (Hash Table & Graph)

Daftar game per konsol
Daftar game berdasarkan genre
Game eksklusif untuk member

🔹 Menu Admin 👨‍💻

Melihat seluruh data member & non-member
Menampilkan daftar game berdasarkan genre
Laporan keuangan total 💰 (member & non-member)

🧠 Konsep Struktur Data yang Digunakan

🌳 Binary Search Tree (BST) → Konsol & Pelanggan

🔗 Linked List & Double Linked List → Member & Riwayat Sewa

🗂 Hash Table → Game Konsol & Game Baru

🕸 Graph (simulasi genre game)

🔁 Rekursif & Traversal Tree (Inorder)
